# 新用户注册后引导设计

## 背景

当前应用已经支持用户自助注册。注册成功后会立即进入亚马逊图片工作台，但新用户首次看到的页面信息密度较高，容易不知道先填商品信息、配置 AI 策划，还是直接生成图片。

本次目标是在不改后端用户体系的前提下，为注册成功的新用户提供一次像游戏教程一样的原生界面上手引导。

## 范围

本次实现：

- 新用户注册成功并进入工作台后，自动显示一次新手引导。
- 引导仅在当前设备按用户 ID 记录完成状态。
- 登录已有账号不会触发引导。
- 引导直接高亮真实工作台区域，而不是只显示独立说明弹窗。
- 引导内容按用户可见界面裁剪：可用 Amazon 策划的账号看到策划相关 5 步；普通注册用户看到历史区和底部直接生图 2 步。
- 用户关闭或完成引导后，本设备不再自动展示。
- 保留顶部问号入口作为后续查看完整指南的路径。

本次不实现：

- 跨设备同步引导状态。
- 后端用户表新增 onboarding 字段。
- 复杂可编辑脚本、管理员配置引导内容。

## 设计选择

采用“注册后一次性原生界面 coach mark 引导”。

备选方案：

- 只显示一条欢迎 toast：改动最小，但无法承载关键流程。
- 多步遮罩 tour：指向性强，但工作台状态较多，容易引入布局和滚动复杂度。
- 一次性上手模态框：信息足够完整，但用户看不到真实下一步位置。
- 原生界面 coach mark：直接高亮真实页面区域，更接近游戏新手教程，成本仍可控。

推荐 coach mark。它能解决新用户的第一步困惑，同时避免为了一个首次引导引入 tour 库或后端状态。

## 触发与状态

触发点放在 `App.handleRegister`：

- 注册 API 返回 authenticated session。
- `loadAccountData(user.id)` 完成。
- 前端检查 `localStorage` 中是否已有当前用户的新手引导完成标记。
- 没有标记则打开新手引导。

完成状态使用本地键：

```text
amazon-image-studio:new-user-onboarding:<userId>:v1
```

值为 `done`。

只在注册成功路径触发，不在普通登录路径触发。这样已有账号不会被打扰。

## 前端组件

新增 `NewUserOnboardingModal`，但视觉行为是 coach mark，不是居中说明弹窗：

- 固定遮罩，真实目标区域高亮。
- 浮层跟随当前高亮区域，包含“新手任务”、步骤进度、说明、提示。
- 支持“上一步 / 下一步 / 完成 / 跳过引导”。
- 关闭、跳过或完成都会记录完成状态，保证只弹一次。
- 完整步骤目标使用稳定 `data-onboarding-target`：
  1. `planner-panel`：认识 Amazon 工作台。
  2. `listing-input`：填入标题、五点描述或品牌说明。
  3. `planner-action`：点击 AI 策划。
  4. `history-panel`：历史筛选和管理。
  5. `input-dock`：底部直接生图入口。
- 普通注册用户当前没有 Amazon 策划入口，因此只展示 `history-panel` 和 `input-dock` 两步，避免指向不存在的界面。

视觉风格沿用现有 modal：

- 高亮区域使用蓝色描边和深色遮罩。
- 浮层使用白底、灰色边框、轻阴影。
- 深色模式配色。
- 8px 左右圆角尺度，避免嵌套卡片。
- 触控目标不低于 44px。

## 测试

使用现有 Vitest 和 `renderToStaticMarkup` 模式：

- `src/lib/onboarding.test.ts`
  - 未记录时返回未完成。
  - 标记完成后返回已完成。
  - 不同用户 ID 使用不同 localStorage key。
- `src/components/NewUserOnboardingModal.test.tsx`
  - 静态渲染包含“新手任务”、进度、下一步和跳过按钮。
  - 导出的步骤 selector 指向真实工作台目标区域。
  - 无 Amazon 策划权限时只渲染普通用户可见的 2 步。

实现后运行：

```bash
npm test -- src/lib/onboarding.test.ts src/components/NewUserOnboardingModal.test.tsx
npm test -- src/components/LoginPage.test.tsx
npm run build
```

前端验收：

- 启动本地服务。
- 注册一个新普通用户。
- 进入工作台后看到真实界面高亮和浮层说明。
- 点击下一步时高亮区域移动到下一个工作台区域。
- 点击完成或跳过后引导关闭。
- 刷新或重新登录同一账号，不再自动展示。

## 自检

- 没有后端字段和迁移，符合本设备一次性展示的选择。
- 触发点明确，只在注册成功后发生。
- 引导覆盖主流程，不重复完整帮助文档。
- 没有引入外部 tour 库或后端同步状态。
